História do Java
R: O Java foi criado em 1995 por James Gosling, na empresa Sun Microsystems. O projeto inicial tinha como objetivo a criação de tecnologias modernas de software para empresas eletrônicas de consumo.A ideia principal do Java era que os aparelhos eletronicos se comunicassem entre si. A frase “Write Once, Run Anywhere” significa “Escreva uma vez, execute em qualquer lugar”, ou seja, um programa Java pode funcionar em diferentes sistemas operacionais sem precisar ser modificado, o que ajudou a tornar a linguagem muito popular.

Diferença entre JDK e JRE
JRE: É o ambiente utilizado para executar programas Java
JDK: É o conjunto de ferramentas usado para desenvolver, compilar e executar programas, pois já inclui a JRE, por isso que quer realmente programar deve instalar o JDK
